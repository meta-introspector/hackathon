# Project Provenance - Educational Game Hackathon

Interactive games teaching data provenance, performance optimization, and systems thinking.

## Games Included

1. **8D Perf Emoji Flying Game** - Navigate performance traces in 8D space
2. **TradeWars 3033** - Space trading with Rust blocks and optimization
3. **Project Provenance** - Educational adventure in data genealogy

## Features

- Real-time performance visualization
- Y Combinator-based game mechanics
- WebGPU 8D navigation
- Creature genealogy puzzles
- Essence crafting system
